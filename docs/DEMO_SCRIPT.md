# Script de démo (≤ 6 min)

1. **0:00-0:40 Problème (angle environnement).** L'air du Sénégal change avec l'harmattan et la sécheresse ; les enfants, les personnes asthmatiques et les travailleurs en extérieur sont les plus exposés. « Les µg/m³ ne disent pas quoi faire. »
2. **0:40-1:30 Maintenant.** Niveau, conseil par profil, masque FFP2 vs tissu, risque de dépasser 100 µg/m³.
3. **1:30-2:40 Planifier.** Mode *travail* : horaire habituel vs conseillé, exposition évitée. Mode *école* : feu tricolore.
4. **2:40-3:20 Sénégal.** Carte des 12 villes, ville la plus chargée, pic prévu.
5. **3:20-4:10 Assistant + Partager.** Question « Mon enfant peut-il jouer dehors ? », puis bouton WhatsApp.
6. **4:10-5:20 Rigueur.** Onglet À propos : baseline, calibration 80 %, Brier vs climatologie, limites.
7. **5:20-6:00 Suite.** Wolof, capteurs locaux, pilote à Thiès.

Avant d'enregistrer : `python train.py --csv data/dakar_hourly.csv`, actualiser les données, tester la clé API.
